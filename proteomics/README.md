Tips about proteomics dataset:

The All of Us v9 proteomics data are provided as normalized Olink NPX measurements in long format, where each row represents one participant/sample × one Olink protein assay. For downstream participant-level analysis, the replicate-removed file, Olink_10k_aou_v9_reps_removed.tsv.gz, should be used. This file contains 54,028,980 rows, corresponding to 9,969 participants/samples and 5,420 Olink protein assays. These assays correspond to 5,416 unique assay names/UniProt IDs.

The data are organized under a single Olink panel, Explore_HT, which is divided into 8 technical blocks. Each participant has measurements across all 8 blocks. The blocks contain unequal numbers of assays: 742, 1,314, 1,204, 1,106, 582, 270, 134 and 68 assays, respectively. The overall missing NPX rate is low, approximately 0.64%.
